# Yakasista Ltd — company website

One-page site for [Yakasista Ltd](https://yakasista.com): software for community safety and local government. Next.js (App Router), TypeScript, Tailwind CSS. Fully static.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Deploy on Vercel (import the repository; no environment variables needed) and point `yakasista.com` at it.
